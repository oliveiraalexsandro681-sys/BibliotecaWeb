# 📚 BibliotecaWeb

Aplicação web desenvolvida em **ASP.NET Core** para gestão de acervo de livros. O projeto inclui interface visual (MVC), endpoints de API RESTful com Swagger e base de dados SQLite, hospedado no Render via Docker.

🔗 **Link do projeto:** https://bibliotecaweb-celj.onrender.com
📖 **Documentação (Swagger):** https://bibliotecaweb-celj.onrender.com/swagger

---

##  Tecnologias Utilizadas

- **Linguagem:** C# (.NET 10)
- **Framework:** ASP.NET Core (MVC & Web API)
- **Base de Dados:** SQLite com Entity Framework Core
- **Documentação:** Swagger (OpenAPI)
- **Containerização:** Docker
- **Hospedagem:** Render
  
##  Funcionalidades

- Listagem, cadastro, edição e remoção de livros (CRUD).
- Endpoints de API REST para integração.
- Criação automática da base de dados e tabelas no arranque.
- Documentação interativa para testes da API.
